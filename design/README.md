# Design explorations

Working files for the design canvas (Claude Design artboards). The seeded `*.html` canvas
output is git-ignored; these `.dc.html` files and `canvas.json` are the source.

## Method (from Anshu Chimala, "How to turn your AI into a world-class designer", Lenny's Newsletter)

- **Seed strings for variety.** Each direction started from a random string, and the
  sub-patterns of the string set the creative direction, so the three options diverge
  instead of clustering around the same safe defaults.
- **Ambitious, specific prompts.** Each direction is a concrete metaphor (darkroom contact
  sheet, trade broadsheet, leaderboard), not "a clean dashboard".
- **Critic pass.** Review screenshots as a design critic separate from the builder: name the
  aesthetic, imagine how a top studio would execute it, list the biggest gaps, score it.
- **Take things away.** No decorative gradients, no glow, no labels where the visual already
  says it, one accent per direction, one number that is allowed to shout.
